# macOS 아날로그 시계 (알람 포함)

iMac 바탕화면에서 띄워둘 수 있는 파이썬(Tkinter) 기반 아날로그 시계입니다.

## 기능
- 아날로그 시계(시/분/초침)
- 상단 날짜 + 요일 표기 (예: `2026년 2월 22일 (일)`)
- 숫자 색상 변경
- 시계 크기 조절
- 알람 설정(시:분) + 알림 팝업 + 시스템 벨

## 실행 방법 (macOS)
1. 터미널 열기
2. 프로젝트 폴더로 이동
3. 아래 명령 실행

```bash
python3 analog_clock.py
```

## 사용 방법
- **숫자 색상**: `색상 선택` 버튼으로 자유롭게 변경
- **시계 크기**: 슬라이더로 크기 조절
- **알람**:
  - `알람 켜기` 체크
  - 시/분 입력
  - 원하는 시간에 팝업 알림
  - `지금 시간으로 맞추기` 버튼은 현재 시각 + 1분으로 자동 입력

## 바탕화면 앱처럼 쓰기 팁
macOS에서 항상 보이게 하려면 다음 중 하나를 사용하세요.
- 앱 실행 후 Mission Control/Stage Manager 활용
- Automator로 `python3 analog_clock.py` 실행 앱을 만들어 Dock에 고정
